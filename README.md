# Arvo documentation

The product documentation for [Arvo](https://github.com/wjpin84/arvo-desktop), the
Financial Intelligence Platform, published at
https://wjpin84.github.io/arvo-docs/ by the workflow in `.github/workflows/docs.yml`.

```
pip install mkdocs-material
mkdocs serve          # http://127.0.0.1:8000, rebuilds on save
mkdocs build --strict # what the workflow runs
```

Code repositories keep only their usage and development notes; decisions and
plans live in [arvo-adrs](https://github.com/wjpin84/arvo-adrs). Everything a
person using Arvo needs is here.
