# Settings

Settings are a file you can read, in VS Code's key names, user then project:

- `settings.json` in the app data directory — yours, everywhere;
- `.arvo/settings.json` in the project folder — this project's, on top.

Settings → *Reveal config file* opens either. The [reference](../reference/settings.md)
lists every key. Keybindings work the same way (`keybindings.json`, VS Code's
chord syntax). Themes come from extensions.
